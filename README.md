# personal-marketplace

Personal Claude Code plugins.

| Plugin | What it does |
|---|---|
| `dev-team` | Stage-by-stage dev workflow (ideate → spec → execute → review → document → archive) for iOS, Android, KMP, Java backend and Angular, written into the Obsidian vault. See `plugins/dev-team/README.md`. |

## Install

```
/plugin marketplace add git@github-personal:jacquat-jonathan/personal-marketplace.git
/plugin install dev-team@personal-marketplace
```

## Check

`bash scripts/check-dev-team.sh` runs the dev-team structural checks and the script unit tests.
